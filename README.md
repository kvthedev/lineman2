Play Texas Hold'em poker with friends online! Free, peer-to-peer, zero server setup required, designed for GitHub Games / GitHub Pages.

## 🎮 How to Play

1. **Password Gate** — Enter `pokerwin` to unlock access.
2. **Choose Name** — Enter your player display name.
3. **Lounge & Global Chat** — Chat with players in the lounge, create a new table, or join with a 6-character code.
4. **Table Lobby** — Join the table with up to 12 players or add AI bots with 1 click.
5. **Start Anytime** — The host can start the game and deal cards whenever, no matter how many people!
6. **Live In-Game Chat** — Chat live at the table with unread notifications and floating seat speech bubbles!
7. **Play** — Full Texas Hold'em rules with keyboard shortcuts:
   - `F` — Fold
   - `C` — Check / Call
   - `R` — Raise
   - `A` — All In

## 🚀 Deploy to GitHub Pages (Free)

1. **Create a new repository** on GitHub (e.g. `poker-game`).
2. **Upload these files** to the repository root:
   - `index.html`
   - `style.css`
   - `poker.js`
   - `README.md`
3. In your repo, go to **Settings → Pages**.
4. Under **Branch**, select `main` (or `master`) and folder `/(root)`.
5. Click **Save**.
6. In ~1 minute, GitHub will give you a public live URL (e.g. `https://<username>.github.io/poker-game/`).
7. Share the link with friends!

## 🔧 Features & Technical Highlights

- **WebRTC Peer-to-Peer**: Powered by [PeerJS](https://peerjs.com/) — direct browser-to-browser sync without any backend server.
- **Physical Dealing Animations**: Dealer deck with deliberate, realistic 3D flying card physics and sequential clockwise deal.
- **Dynamic Table Sizing**: Table smoothly expands and repositions seats dynamically based on player count (1–12 players).
- **Built-in AI Bots**: Add smart AI bots to practice solo or fill seats (up to 11 bots).
- **Complete Rules**: Side pot calculation, split pots, all-in showdowns, and live hand rank evaluator.
